### Strang 2.1
Matrices can be viewed in either the column picture or the row picture as lines/planes/hyperplanes intersecting to meet at a point or as column vectors being scaled and added together to reach a solution vector. Systems of linear equations can be transformed into the form Ax = b where A is the coefficient matrix, x is the input vector and b is the solution vector.

### Strang 2.2
We can solve systems of linear equations through the process of elimination.  First we define pivots as the first non-zero entries along the diagonal of a coefficient matrix A in the matrix equation Ax = b. The process of elimination is as follows: we take the first pivot and our goal is to reduce all equations below the pivot to 0 by the process of row operations, in this case subtracting from the row containing the term we want to reduce to 0 by the row with the pivot multiplied by a certain multiplier l which we get by dividing the terms coefficient with the pivot number. once we have all zeros below the pivot we move on to the second pivot and we repeat the process until we're left with an upper triangular matrix where below the pivots are all zeros and then we can solve the system by back-substitution because the last row only contains one term for example 5z = 10, we find z and substitute it upwards until we solve every unknown. sometimes if the last row left side ends up being 0 that means there is not solution and elimination failed, but if the right side is also 0, so 0 = 0 then we know we have infinite solutions and the dimension of the solution set is the number of unknowns minus the number of pivots.

### Strang 2.3 
The row operations used during the process of elimination can be written in matrix form as

* E_ij - Elimination matrix that is used to subtract a multiple of row j from row i in any matrix,

* as well as a permutation matrix P_ij which can be used to switch rows i and j in any matrix A, which is useful if have a zero-pivot and we need to switch rows to continue elimination.

Using matrix multiplication of we can apply the elimination and permutation matrices to our matrix equation. since the steps are applied to both sides of the equation, the equation looks like this: EAx = Eb.

We can have many elimination matrices and permutation matrices chained together in matrix multiplication to transform a matrix to upper triangular form in several steps such as EPEEAx = EPEEb, several matrix multiplications are applied right to left.

We can also collapse all these elimination and permutation matrices into 1 step due to the associative law being true for matrices (C(BA)x = (CB)Ax), by multiplying them and it will achieve the same result with 1 matrix multiplication,

Also for matrix multiplication it's important to know that the commutative law is false so AB != BA.

Also we can quickly write down an elimination step as a matrix by finding the elimination multiplier L_ij, multiplied by -1 and placing it in position i,j of an identity matrix to get elimination matrix E_ij.

### Strang 2.4

There are several rules for matrix operations
- To add or subtract matrices they need to have the same shape m x n
- To perform matrix multiplication the 2 matrices need their inner dimensions to match such as m x n * n x p, where n is the inner dimension.
- Matrix multiplication is associative (AB)C = A(BC), but not commutative AB != BA, except for some rare cases and multiplication by the identity matrix I (AI = IA)
- Matrices are distributive: (A+B)C = AC + BC

Matrices can be multiplied in 4 different ways
- Rows of A x Columns of B, by doing the dot product of these 2 vectors we get 1 entry in AB at a time at position AB_ij, where i is the row of A and j is the column of B
- Matrix of A x Columns of B, gives us one column of AB at a time.
- Row of A x Matrix of B, gives us one row of AB at a time
- Columns of A multiply rows of B as if each row and column is a matrix, so we perform matrix multiplication instead of a dot product and then we add together the resulting matrices.

There also exists a way of simplifying multiplication by blocks, if 2 matrices can be simplified into blocks you can add them together a block at a time and if the shapes allow it you can also multiply matrices a block at a time

### Strang 2.5

An inverse matrix denoted as A^-1 is a matrix that reverses the transformation by matrix A. Not all matrices have an inverse, if a matrix doesn't have an inverse it's known as a singular matrix.

There are a few key ways to find out if a matrix is invertible:
- Determinant is not zero. This comes from the fact that the determinant is a number that tells us the factor of how much the matrix scales spaces, if the determinant is 0, the matrix squashes space into the zero vector, destroying information, therefore it cannot be reversed due to permanent loss of information.
- In a square matrix n x n, there are n non zero pivots, during the process of elimination if we can achieve a triangular matrix with n non-zero pivots then we know the matrix is invertible.
- Diagonal dominance - if every (absolute) entry on the diagonal is larger than the absolute sum of the rest of the entries along the pivot row, the matrix is guaranteed to have an inverse
- There must not be a non-zero input vector x, so that the solution becomes a zero vector. Once again this causes loss of information

This chapter introduces Gauss-Jordan elimination, which is a method to solve matrix equations. It builds on gauss elimination, by reducing the matrix from upper triangular form to the identity matrix, basically doing the same row operations on the numbers above the diagonal and then dividing out each row by the pivot entry. We also augment the right side of the equation while doing this and after elimination the left side becomes the identity and the right side becomes the input vector x. This removes the need for back substitution.

We can actually solve for a matrix inverse using Gauss-Jordan elimination. If we take the definition of an inverse matrix AA^-1 = I, we can solve for A^-1 if we take individual columns of A^-1 and I and perform gauss-jordan elimination for each column where the column 1 of A^-1 is the input vector and col. 1 of I is the solution vector. and using gauss-jordan we can find the first column of the inverse matrix. And then we do the same for the rest of the columns to find the full inverse matrix. We can speed this up by actually computing all of the columns simultaneously by augmenting all the columns I = (e1, e2, e3) onto our matrix A and performing gauss-jordan. And then our augmented matrix [A, I] turns into [I, A^-1].

### Strang 2.6

Any square matrix A (that doesnt need permutation to solve) can be factorised into a product of 2 matrices L and U where L is lower triangular and U is upper triangular. We uncover these 2 matrices naturally through the process of elimination, where when we do elimination and reach upper triangular form - U thats our U matrix and L is the inverse matrix of all elimination steps taken so far assuming theres no permutation needed to reach U. So if we apply L to U we get A, So A = LU. If EA = U (1 elimination step) then A = E^-1U and we denote E^-1 as L.

The matrix L has 1's on the pivots. and each entry below the diagonal is multiplier l_ij for that row operation. Where as multiple elimination matrices combined contain flipped sign multipliers 'l' and are usually messy, L usually is very neat and the multipliers sit in their original positions when the reversed steps are combined. Important to note that U has the pivots of the matrix on its diagonal.

When computers solve Ax = b, they start with the first subroutine to eliminate A to reach U, the elimination steps are stored in L, and then only after we reach U the computer applies the steps we saved in L to apply onto b. This is the same as solving Lc = b, where c is b with the elimination steps applied, which is what were looking for. After finding c we solve Ux = c, which is basically back substitution.

To solve a triangular system it takes n^2/2 multiplications and n^2/2 subtractions. Elimination to find U takes n^3/3 multiplications and subtractions.
