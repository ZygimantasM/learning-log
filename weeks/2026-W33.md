## What I learned
Strang 3.2 - Null space denoted as N(A) is vector space or set of vectors that satisfies the equation Ax = 0. Every invertible matrix always has N(A) = {0} (zero vector). If the matrix is not invertible (columns != pivots | n != r ) There can be more solutions to Ax = 0 than just the zero vector.

The null space in lives in R^n when matrix A is m x n, meanwhile C(A) lives in R^m. The rank of matrix A is denoted as r, and all of these numbers interact with this formula = n-r = nullity(A) or the dimension of the null space.

Generally the way to find N(A) of a matrix is this

1. Reduce A to RREF (Reduced row echelon form, same as elimination, but we clear above each pivot and divide pivot rows by pivot to get 1's on the pivots). If the rank == no. columns, stop right there, null space is just the zero vector
2. For every free variable in reduced A(doesnt have a pivot in the column) set it to 1 and the other free variables set to 0.
3. Write out the matrix equation Ax = 0 in non-matrix form. Then solve for the pivot variables in terms of the free variables and construct a solution vector x, factor out the free variable and were left with a special solution s1 that when multiplied by any scalar c, cs1 = 0. Then move on to other free columns and do the same step to find every special solution. You can see how many there will be by finding n - r.
4. Then N(A) is a linear combination of every special solution cs1 + ds2 and so on.

The special solutions such as s1 = [3, 0, 2] tell us what combination of the columns result in a zero vector, so in this case 3x col 1 + 2x col 3 = 0.
