## What I learned
- Strang 2.1 - Matrices can be viewed in either the column picture or the row picture as lines/planes/hyperplanes intersecting to meet at a point or as column vectors being scaled and added together to reach a solution vector. Systems of linear equations can be transformed into the form Ax = b where A is the coefficient matrix, x is the input vector and b is the solution vector.

- Strang 2.2 - We can solve systems of linear equations through the process of elimination.  First we define pivots as the first non-zero entries along the diagonal of a coefficient matrix A in the matrix equation Ax = b. The process of elimination is as follows: we take the first pivot and our goal is to reduce all equations below the pivot to 0 by the process of row operations, in this case subtracting from the row containing the term we want to reduce to 0 by the row with the pivot multiplied by a certain multiplier l which we get by dividing the terms coefficient with the pivot number. once we have all zeros below the pivot we move on to the second pivot and we repeat the process until we're left with an upper triangular matrix where below the pivots are all zeros and then we can solve the system by back-substitution because the last row only contains one term for example 5z = 10, we find z and substitute it upwards until we solve every unknown. sometimes if the last row left side ends up being 0 that means there is not solution and elimination failed, but if the right side is also 0, so 0 = 0 then we know we have infinite solutions and the dimension of the solution set is the number of unknowns minus the number of pivots.
