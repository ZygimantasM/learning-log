Strang 3.2 - Null space denoted as N(A) is vector space or set of vectors that satisfies the equation Ax = 0. Every invertible matrix always has N(A) = {0} (zero vector). If the matrix is not invertible (columns != pivots | n != r ) There can be more solutions to Ax = 0 than just the zero vector.

The null space in lives in R^n when matrix A is m x n, meanwhile C(A) lives in R^m. The rank of matrix A is denoted as r, and all of these numbers interact with this formula = n-r = nullity(A) or the dimension of the null space.

Generally the way to find N(A) of a matrix is this

1. Reduce A to RREF (Reduced row echelon form, same as elimination, but we clear above each pivot and divide pivot rows by pivot to get 1's on the pivots). If the rank == no. columns, stop right there, null space is just the zero vector
2. For every free variable in reduced A(doesnt have a pivot in the column) set it to 1 and the other free variables set to 0.
3. Write out the matrix equation Ax = 0 in non-matrix form. Then solve for the pivot variables in terms of the free variables and construct a solution vector x, factor out the free variable and were left with a special solution s1 that when multiplied by any scalar c, cs1 = 0. Then move on to other free columns and do the same step to find every special solution. You can see how many there will be by finding n - r.
4. Then N(A) is a linear combination of every special solution cs1 + ds2 and so on.

The special solutions such as s1 = [3, 0, 2] tell us what combination of the columns result in a zero vector, so in this case 3x col 1 + 2x col 3 = 0.

Strang 3.3 - We can write every solution to Ax = b in the form x = (x_p + x_n) where x_p is the particular solution and x_n is a special solution to Ax = 0.

A particular solution is any arbitrary solution that we pick  from the set of all possible solutions. The simplest way to find one in the case where we have free columns in our matrix is to set the free variables to 0 and compute the solution with only pivot variables, that becomes our x_p. If the rank of our matrix equals the columns of our matrix and we dont have free variables, theres only one particular solution.

The way to understand why we can write every solution as x_p + x_n is like this: A(x_p + cx_n) = Ax_p + Acx_n = b + 0 = b, so when we add any multiple of a special solution the solution is still valid. Also if we take A(X - x_p) = Ax - Ax_p = b - b = 0, than means x - x_p is in the nulspace so x = x_p + x_n. We can look at it geometrically, if the equations of Ax = b are a line, the equations of Ax = 0 are also a line parralel to Ax = b. Adding x_n to x_p pushes x_p along that line. Even in cases where Ax = b has 1 solution it can be written in this form, where x_n is just the zero vector.

Some other quick rules about how to tell how many solutions a matrix can possibly have is by looking the no. of rows and columns: m, n. and the rank of the matrix: r.

The number of columns in the matrix proportionate to the rank dictate the uniqueness of our solutions: is there 1 solution or infinite solutions? In the case n > r, we have free columns, and if we have atleast 1 solution then we also have infinite solutions, if n = r then theres at most only 1 solution.

The number of rows in the matrix proportionate to the rank dictate the existance of a solution: is it possible that there is no solution to a matrix equation? In the case of m > r, we have non-pivot rows that impose constraints on our right-hand side b that it has to match in order to be a valid b, therefore restricting the column space. The equation then can have no solution for some b, but it ALWAYS has atleast one b that has a solution. If m = r then there are no constraints are there will always be atleast 1 solution.

If we combine both of these rules, then if m = r = n we will always have exactly 1 solution regardless of b, then if we have m > r and n > r we can have 0 solutions or infinite solutions depending on b.
