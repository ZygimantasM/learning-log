## What I learned
Strang 2.7 - The tranpose of matrix A denoted as A^T is an operation where the rows of matrix A become columns of matrix AT or vice versa or in other words the entries of A - A_ij become A_ji. Some rules for matrix transposes:
- (A + B)^T = A^T + B^T
- (AB)^T = B^TA^T
- (A^-1)^T = (A^T)^-1
The definition of the Matrix transpose is an identity, where the matrix A^T satisfies the equation:

(Ax)^Ty = x^T(A^Ty) 

The dot product of 2 vectors can be written as x^Ty instead of x * y (This is the inner product and ends up as a single number because the inner dimensions match 1 x n * n x 1 = 1x1 matrix or single number)
If we take the transpose of y then we get xy^T (outer product) and the result is a matrix n x n.

Permutation matrix - Matrix P that switch the rows of another matrix A (PA). If right-multiplied (AP) then switches the columns. A permutation matrix starts as an identity matrix I where the rows are switched around to give the desired row exchange operation. Some rules for permutation matrices.
- Transpose of P - P^T is equal to it P's inverse P^-1. P^T = P^-1
- Some permutation matrices are inverses of themselves, specifically when there is 1 row exchange operation, if you switch rows 2 and 3 twice you end up where you started. Same thing goes for multiple disjoint row exchanges in a single matrix. There also cyclical permutations, where if you perform the permutation a few times the matrix ends up where it started e.g. rows: 1->2 2->3 3->1

Symmetric matrix - A matrix is symmetric if S = S^T. Some rules:
- If matrix S is symmetric S^2 will also be symmetric
- If we take any non-symmetric matrix m x n A and multiply by its transpose AA^T OR A^TA we end up with 2 possible symmetric matrices depending on which way we multiplied. if AA^T we get an m x m matrix (outer multiplication) or if A^TA then n x n matrix (inner multiplication)

S = LDL^t factorization:
If we factorize a symmetric matrix S into S = LDU we will get S = LDL^T, Where our U matrix is actually the transpose of L (Since the matrix is mirrored the elimination steps we need to take are exactly the same but mirrored above the diagonal so U = L^T), this makes the factorization more efficient because we need to store only half of the values and do half of the computations.

PA = LU Factorization. Up until now we've assumed that when we factor A = LU that along the way the matrix A doesn't need a row exchange to continue elimination to reach U. But if we need a row exchange we can actually bring it out in front of A as PA = LU, so first we perform the necessary row exchanges before doing elimination and factoring into LU. this can also be written as A = P^-1LU as well as A = P^TLU because P^T = P^-1

Strang 3.1 - Vector spaces are the set of all possible vectors of that dimension. Vector spaces of column vectors are denoted as R^n where n is the dimension of the vectors. Denoted as R because the column vectors contain real numbers, similarly there are alo non-conventional vector spaces like matrices M^n, complex numbers C^N, zero vector space Z.

Subspaces are subsets of vector spaces that have to follow key rules to be considered subspaces. Every vector space is a subspace of itself. Basically a subspace is what we get when we take linear combinations of 1 or more vectors. The span of these linear combinations is the whole subspace, so given a linear combination(of independent vectors) cv + dw in R^3 we get at most a plane subspace in r3

The key rules:
* the zero vector must be included in the subspace (the subspace as a line, plane or point must pass through the origin)
* 2 vectors that are added together stay in same subspace
* vectors that are scaled by a scalar number stay in the same subspace

Column space denoted C(A) is the set of all possible linear combinations of the columns of A. Different kinds of A will produce a different kind of column space. If a matrix is invertible it will always result in C(A) taking up all of space, but if the matrix is singular the column space will end up spanning space in a dimension lower than the vector space. if we have  m x n Matrix A, the vector space will be R^m and if n < m, the biggest possible C(A) can be of dimension n so in a case of 3 x 2, the matrix column space will at most be a 2d plane in 3D space.

If a certain b we are trying to find x for exists outside of that matrices column space, it is impossible to find x.
